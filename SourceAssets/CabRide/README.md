# Исходники режима «Живая кабина»

Рабочий Unity-проект находится в `D:\Projects\Unity\Trains_Match`.

- `References` — неизменённая копия исходной фотографии кабины.
- `ImageGen-Raw` — все 13 необработанных изображений, созданных ImageGen в ходе работы.
- Готовые прозрачные PNG, промежуточные варианты с цветовым ключом и описание обработки находятся в `Assets/SortingStation/Art/Cab`.
- Исходный код режима, редакторских окон и проверок находится в `Assets/SortingStation`.
- Результаты последних проверок и smoke-скриншоты находятся в `Logs`.

Оригинальные файлы во внешних папках не удалялись и не изменялись. APK и Windows-сборка на этом этапе не создавались.
